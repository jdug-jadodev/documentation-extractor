# Documentar un flujo o endpoint

Reemplaza los valores entre corchetes. El consumidor es opcional.

```text
Documenta cómo funciona el flujo de [MÉTODO HTTP] [RUTA] en [REPOSITORIO O
SERVICIO]. Si aplica, trázalo desde [CONSUMIDOR O PUNTO DE ENTRADA] hasta el
destino final.

Usa el conocimiento vigente del sistema de documentación. Incluye el punto de
entrada, construcción de la URL, endpoint receptor, router, middleware,
controlador, servicios, métodos, datos, dependencias, respuesta observable y
cada salto entre repositorios.

Genera el Markdown en Obsidian con un Mermaid propio del flujo. Señala la
evidencia, las relaciones candidatas y lo que no pueda demostrarse. No inventes
cuerpos, códigos HTTP ni comportamiento.
```
