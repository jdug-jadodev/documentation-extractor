# Relación entre sistemas

Reemplaza los valores entre corchetes.

```text
Explica y documenta cómo se comunica [SISTEMA ORIGEN] con [SISTEMA DESTINO].

Usa el conocimiento vigente del sistema de documentación. Muestra las llamadas,
endpoints, contratos observables, datos involucrados, dependencias y el camino
extremo a extremo. Genera un Mermaid claro y guarda el resultado en Obsidian.

Trata ambos repositorios como sistemas independientes. Distingue relaciones
confirmadas, candidatas y no resueltas, e incluye la evidencia disponible.
```
