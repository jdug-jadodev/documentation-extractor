# Flujo de registro: estraviado a login-estraviado

```text
Usa el run más reciente que contenga estraviado y login-estraviado.
No reanalices.

Documenta el flujo de registro desde estraviado hasta
login-estraviado.

Necesito:

1. Punto de entrada en estraviado.
2. Archivo que inicia la llamada.
3. Método HTTP y construcción de la URL.
4. Endpoint completo recibido por login-estraviado.
5. Montaje del router.
6. Middleware observado.
7. Handler y controlador.
8. Caso de uso.
9. Repositorios y adaptadores.
10. Entidades o tablas consultadas y modificadas.
11. Respuesta que puede demostrarse.
12. Dependencias externas.
13. Camino extremo a extremo.
14. Riesgos y puntos no demostrados.
15. Evidencia exacta para cada salto.

Genera el resultado en Markdown para Obsidian y añade un diagrama
Mermaid propio de este flujo. Reserva Archify para el mapa general de
arquitectura.

No presentes como supported una relación candidate.
No inventes cuerpos, códigos HTTP ni orden de ejecución.
```
